株式会社ワイエムジーワンの求人内容を参考にした、応募用の非公式自主制作です。企業の公式サイト・公式制作物ではありません。

## Preview

Open `index.html` in a browser. The page uses local CSS, JavaScript, and the images in `assets/`.

## Project files

- `index.html`: page structure
- `styles.css`: responsive styles
- `script.js`: small page interactions
- `assets/`: images used by this LP
- `cording_template/css/reset.css`: reset stylesheet used by the page
